Genomic DSL Syntax Reference

Pipelines are declared using the top-level pipeline <identifier> { ... } construct containing ordered step sequences.

1. Pipeline Declaration: pipeline <PipelineName> { <step_statements...> }
2. Step Syntax: step <step_id>: TOOL_NAME(param1: val1, param2: val2)
3. Inter-Step Dependency Link: step 02: BWA(reads: 01_trim.output, ...) // Resolves to output artifact of step 01_trim
4. Supported Literals: Strings ("sample.fq.gz"), Integers (8), Memory ("16G")

Client Integration Snippet (POST /analyze)

Prototype integration reference showing request structure for dispatching AST jobs to the Python/FastAPI backend: 

// Target schema: POST /analyze & GET /health
async function analyzeGenomicPipeline(dslCode) {
  const API_BASE = 'http://localhost:8000';
  
  const response = await fetch(`${API_BASE}/analyze`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ dsl: dslCode })
  });

  if (!response.ok) throw new Error('Analysis failed');
  return await response.json(); // { status, errors, ast, glm_risk }
}
